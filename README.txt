# 3D Print Shop

Веб-приложение интернет-магазина услуг 3D-печати с административной панелью, системой заказов и загрузкой пользовательских моделей.

## Описание проекта

Данный проект представляет собой полнофункциональный веб-сайт для предоставления услуг 3D-печати. Пользователь может просматривать товары, добавлять их в корзину и избранное, оформлять заказы, отправлять индивидуальные заявки на печать с загрузкой файлов, а также связываться с администрацией через форму обратной связи.

Администратор имеет доступ к панели управления, где может управлять товарами, категориями, заказами, изображениями и сообщениями пользователей.

Проект разработан с использованием базовых веб-технологий и ориентирован на практическое применение.

## Функциональность

### Пользовательская часть

- Регистрация и авторизация пользователей
- Просмотр каталога товаров
- Просмотр подробной информации о товаре
- Добавление товаров в корзину
- Добавление товаров в избранное
- Оформление заказа
- Отправка индивидуального заказа с загрузкой 3D-модели
- Форма обратной связи
- Мультиязычный интерфейс (русский, английский, эстонский)

### Административная панель

- Просмотр статистики (пользователи, товары, заказы, сообщения)
- Управление товарами (создание, редактирование, удаление)
- Управление категориями
- Загрузка изображений товаров
- Установка главного изображения товара
- Удаление изображений
- Просмотр и обработка заказов
- Просмотр индивидуальных заказов
- Просмотр сообщений пользователей
- Отметка сообщений как прочитанных

## Используемые технологии

- PHP (без использования фреймворков)
- MySQL / MariaDB
- HTML
- CSS
- PHPMailer (для отправки email)
- XAMPP (локальная среда разработки)

## Мультиязычность

Сайт поддерживает три языка:

- Русский
- Английский
- Эстонский

Для реализации мультиязычности используются отдельные поля в базе данных:

- name_ru, name_en, name_et
- description_ru, description_en, description_et

Язык переключается через интерфейс сайта.

## База данных

Проект использует реляционную базу данных MySQL.

Основные таблицы:

- users — пользователи
- categories — категории товаров
- products — товары
- product_images — изображения товаров
- orders — заказы
- order_items — позиции заказа
- custom_orders — индивидуальные заказы
- contacts — сообщения пользователей
- wishlist — избранное
- cart_items — корзина
- order_statuses — статусы заказов
- order_status_history — история изменения статусов
- settings — настройки сайта

## Загрузка файлов

Изображения товаров хранятся в файловой системе:

/uploads/images/

3D-модели пользователей:

/uploads/models/

В базе данных сохраняется только путь к файлу.

## Email уведомления

Для отправки сообщений используется PHPMailer с SMTP через Gmail.

Пример конфигурации:

```php
return [
    'mail' => [
        'host' => 'smtp.gmail.com',
        'username' => 'your_email@gmail.com',
        'password' => 'app_password',
        'port' => 465,
        'from_email' => 'your_email@gmail.com',
        'from_name' => '3D Print Shop',
        'admin_email' => 'your_email@gmail.com',
    ],
];
````

Используется App Password, а не обычный пароль Gmail.

## Установка проекта

1. Склонировать или скачать проект

2. Поместить в папку htdocs (если используется XAMPP)

3. Запустить Apache и MySQL

4. Открыть в браузере:

[http://localhost/3d_print_shop/install.php](http://localhost/3d_print_shop/install.php)

5. После выполнения установки база данных создастся автоматически, а также будут добавлены тестовые данные.

## Структура проекта

/3d_print_shop

* admin/ — административная панель
* includes/ — подключение к базе данных и вспомогательные функции
* mail/ — отправка почты и шаблоны писем

Основные файлы:

* index.php — главная страница

* cart.php — корзина
* contacts.php — форма обратной связи
* install.php — установка проекта
